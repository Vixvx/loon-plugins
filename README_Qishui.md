# 汽水音乐广告任务监控 V1（Loon）

> 仅适用于用户本人正常播放广告、检查任务奖励是否到账的网络诊断。**不自动看广告，不伪造完成事件，不发送领取请求，不修改任何响应。**

## 一键订阅

在 Loon → 插件 → 添加插件 → 填入：

```
https://raw.githubusercontent.com/Vixvx/loon-plugins/main/Qishui_Reward_Monitor.plugin
```

打开插件，确保 Loon 的 MitM 根证书已安装并被系统完全信任。插件只声明两个已在本机 HAR 验证的域名：`api.qishui.com`、`beta-luna.douyin.com`。HTTPS 解密会接触到账户相关流量，请仅在自己设备上使用。插件本身不读取或存储请求 Cookie、Authorization、Token、请求体、查询参数、设备标识和账号信息，也不向外发送数据。

## 监控信息

- 广告配置与素材请求：`/luna/advert/incentive/config`、`/retrieve`、`/luna/ads/config`、`/luna/ads/dsp/retrieve`；
- 广告完成信息：`/luna/advert/fallback/done/info`（兼容 HAR 中的双斜杠）；
- 广告完成及奖励响应：`/luna/advert/incentive/done`，只显示 HTTP 状态、业务状态、匿名奖励数量和领奖状态值；
- 任务确认：`/luna/treasure/task/page/v2` 的 `luna_rewards_ads` 任务进度，检查已解锁天数、当前目标日、完成子任务数和“再看 N 次”的变化。

**计数定义：**“广告完成响应成功”只表示完成接口返回成功；“服务端确认进度 + N”则是上、下两次任务响应中同一节点的 `is_completed` 从 `false` 变成 `true`，不是自动计算奖励额度。若首次监控时任务已经完成，插件不会将已存在的进度算作本次领取。

## 查看日志

正常打开汽水音乐 → 会员/畅听任务页 → 完整观看广告，重新打开任务页刷新进度。

随后在 Loon 的「脚本」页面运行 Generic Script **“汽水音乐 · 查看脱敏报告”**，会发出一条摘要通知，并在脚本日志中显示最近 15 条事件。插件最多保留 40 条脱敏事件。

如需重置本地统计，运行 **“汽水音乐 · 清空本地监控记录”**。这只会清除本插件的本地记录，不会操作汽水音乐账号权益。

## 常见问题

- **没日志**：请检查 MitM 开关、系统根证书信任、脚本是否命中。注意本机其他去广告插件可能先拦截请求。
- **广告打不开**：用户之前配置启用了 `blockAds.plugin`、`BlockAdvertisers.lpx`、`Block_HTTPDNS.lpx`。建议先临时停用疑似冲突插件，逐个确认；本插件不会绕过它们的拦截规则。
- **完成请求成功、但已计入次数没有增加**：返回任务页面刷新，确认服务端任务进度；可能因为未刷到任务页、任务变化结构不同、已有基线过旧或奖励正在处理。
- **进度增加、畅听天数不变**：例如第 27 天需要看 3 次广告，目前看了 1 次并不等于已解锁第 27 天。
- **数据异常**：当前解析规则依据汽水音乐 iOS 21.5.0 的 2026-11-08 HAR 验证。如果接口结构变化，需要提供新的**脱敏抓包**更新规则。

## 开发/测试说明

- Loon 新脚本语法：最低 3.5.1 (983)；`response if ... then script(...)` 和 `generic then script(...)`。
- 只包含 `[Script]` 和 `[Mitm]` 模块，**没有 `[Rule]` 或 `[Rewrite]`，没有额外发起网络请求**。
- 核心 JS 统一通过 `$done({})` 放行原始 HTTP 响应；请求和响应不会被修改。
- HTTP 的 200 和业务码 0 与「奖励计入任务」是不同的事件，分别显示。
- 不会把 HAR、IPA、个人 Loon 配置或密钥上传到 GitHub。
